Self-hosted latin webfonts for Inland Empire Native Nursery.

Fraunces (italic 600; italic 560-600; roman 560-650) is the official latin
subset from Google Fonts / fonts.gstatic.com, version v38, SIL Open Font
License 1.1 (OFL-Fraunces.txt). Used for the shop slogan and the About page.

Teaser heading fonts (only the active one is loaded, by teaser.js, when the
starter teaser is about to show): Dancing Script 700, Baloo 2 800, Fredoka 700,
Lilita One 400, Rubik 800, Bricolage Grotesque 800. Official latin cuts, OFL
or equivalent, from fonts.gstatic.com. Dancing Script is no longer loaded on
every homepage visit; it is only fetched if the teaser font is set to dancing.
