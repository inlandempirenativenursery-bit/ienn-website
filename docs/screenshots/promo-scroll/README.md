# Promo banner – red scroll style (Eric's direction)

Pure CSS (no images) in `promo.js`, used on `index.html` and `order.html`. A dim see-through overlay covers the page. The banner is a bold red ribbon (#C1121F) with rolled ends and notched tails (#8B0D16) and cream text (#FFF8E7). The title, message, discount note and dates come from the active Promos row. To close it, tap outside, tap ×, press Esc or tap "Shop now". It plays a short unroll animation, which is turned off under prefers-reduced-motion.
