## Caveats
- **Showy milkweed:** `showy-milkweed.jpg` exists but the catalogue says "Photo coming". The plant has narrow, trough-folded, densely woolly leaves, which looks more like **Woollypod (A. eriocarpa)** than Showy (A. speciosa has broad, flat, veined leaves). Ask Eric to confirm; Eric has no A. speciosa iNat observations.
- **keithwg1 photos** (buckwheat, encelia, morning glory, yucca): not Eric's. Need Keith's OK before use. ★ picks avoid them except Encelia and Morning glory, which have no alternative.
- **Species checks:** Showy penstemon options are all P. spectabilis. Scarlet bugler options are P. centranthifolius (Eric's iNat incl. Fontana). Milkweed rows use only their own species (A. fascicularis / A. speciosa / A. eriocarpa); A. californica excluded.
- **No photo:** Deergrass.
- Dropped (not on the real list): Ceanothus, Toyon, Coyote brush, Woolly blue curls, Arizona cypress, other iNat-only plants. The Ceanothus moth is excluded.
